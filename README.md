# EdgeGuard – HIL Predictive Maintenance

## Project flow

775 DC Motor
-> 12 V PWM Controller
-> Relay
-> ACS712
-> ESP32 sensors/control
-> USB serial
-> Raspberry Pi 4
-> preprocessing
-> SVM
-> telemetry.jsonl
-> Streamlit dashboard

## Files

- `app1.py` – Streamlit dashboard
- `bridge.py` – Raspberry Pi serial bridge + ML + optional relay command
- `preprocessing.py` – telemetry normalization/features
- `ml_engine.py` – SVM loading/prediction + fallback
- `train_model.py` – creates the initial demonstration SVM
- `config.py` – paths, thresholds and settings
- `requirements.txt` – Python packages
- `firmware/edgeguard_esp32.ino` – ESP32 firmware
- `data/telemetry.jsonl` – live telemetry log
- `models/edgeguard_svm.pkl` – generated by `train_model.py`

## Quick start on Raspberry Pi

```bash
mkdir -p ~/edgeguard
cd ~/edgeguard

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python train_model.py
```

Find the ESP32 port:

```bash
ls /dev/ttyUSB*
ls /dev/ttyACM*
```

If the result is `/dev/ttyUSB0`, run:

```bash
export EDGEGUARD_SERIAL_PORT=/dev/ttyUSB0
python bridge.py
```

In another SSH terminal:

```bash
cd ~/edgeguard
source venv/bin/activate
streamlit run app1.py --server.address 0.0.0.0 --server.port 8501
```

Open the dashboard from a browser using the Raspberry Pi IP:

`http://PI_IP_ADDRESS:8501`

## Important ML note

The supplied `train_model.py` creates a synthetic demonstration SVM so the software
works immediately. It is not experimental proof of predictive accuracy. For a real
project evaluation, collect labeled motor data and retrain the SVM.

## Important hardware note

Do not use automatic relay shutdown until:
1. relay operation is tested with the motor power disconnected;
2. the ESP32 command protocol is verified;
3. ACS712 current measurement is calibrated;
4. the relay and wiring are confirmed to be rated for the motor's startup/stall current.

A 5 V ACS712 output must not be connected directly to an ESP32 GPIO unless its
voltage is limited to the ESP32-safe range. Use a proper divider/interface.
